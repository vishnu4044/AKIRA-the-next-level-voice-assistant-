# AKIRA – Voice Assistant with Authentication

Published in *Springer, Advances in Intelligent Systems and Computing* (2021).  

## 📌 Important Note
This project **AKIRA – Voice Assistant with Authentication** is part of copyrighted academic work.  
Due to intellectual property rights, the **source code is not publicly available** in this repository.  

This GitHub repository only contains documentation and project details for reference purposes.

AKIRA is a Python-based **voice assistant** designed with an integrated **authentication system**. Unlike regular voice assistants, AKIRA ensures secure execution of sensitive commands by differentiating between **permission-less** and **permissioned** tasks.

## ✨ Features
- 🎙️ Voice-based interaction using speech recognition
- 🔒 Authentication system for permissioned commands
- ⚡ Executes system-level tasks (open apps, search, etc.)
- 🛡️ Prevents unauthorized access with secure command handling
- 🖥️ Lightweight and easy to set up on laptops/desktops

## 🔧 Tech Stack
- **Programming Language:** Python 3.x  
- **Libraries Used:**
  - SpeechRecognition  
  - Pyttsx3 (text-to-speech)  
  - OS, Sys (system commands)  
  - Other dependencies (see `requirements.txt`)  


## 🔐 Authentication Workflow
- **Permission-less Commands** → Run directly (e.g., "What’s the time?", "Open browser").  
- **Permissioned Commands** → Require authentication (e.g., "Shut down system", "Access personal files").
